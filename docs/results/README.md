# LongVideoBench 结果与来源摘要

本目录保存从已封存本机实验中提取的精简结果，不包含权重、视频、题目全文、逐题模型输出或本机环境转储。
准确率显示为百分数；JSON 中保留比例值与未四舍五入的统计量。样本方差使用三个 seed 的 ddof=1，表内单位为百分点²。

随机选边每个 seed 重复50次；先求seed内准确率均值，再计算跨seed方差。OR是使用真实标签的上界。

两基线为4 FPS/4096帧；Controller两源为2 FPS/2048帧、β=2；上下文262144，视觉token预算24576，不使用字幕或音频。

## 文件与验收口径

- [longvideobench_summary.json](longvideobench_summary.json)：五张表的数值、协议、模型版本及源文件SHA。
- [proportional_samples.json](proportional_samples.json)：比例采样的三份问题ID、配额、样本和标注SHA；不含题目文本。

比例实验实际完成12个模型和7个CPU子步骤，均真实退出0；独立CPU重验进程也真实退出0，随后封存并复查382项文件。原外层wrapper退出码缺失，记录为unknown，没有补造full.exitcode。旧等量实验的2185项清单亦经逐项SHA核验。

公开JSON是提取后的摘要，其SHA自然不同于原始完整results.json；`source.sha256`明确指向本机原始文件。原始源清单包含本机路径与运行信息，因此未将完整runs/reports上传。

三个seed不足以证明统计显著性；两协议不是严格算力对齐；未获得完整QA训练清单，训练/验证重叠尚未核实。
